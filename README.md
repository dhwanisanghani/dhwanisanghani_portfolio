# Dhwani Portfolio

A complete static portfolio, ready for GitHub Pages. No build command or package installation is required.

## Section order

1. Hero Section
2. Education
3. Experience
4. Expertise
5. Industry
6. Tools
7. Contact

The original section content, embedded artwork, video, typography, animations and interactions are retained in one `index.html`. Some original fonts use Google Fonts or external fallback URLs; system fallbacks apply when those services are unavailable.

## Publish with GitHub Pages

1. Extract this ZIP.
2. Upload `index.html`, `.nojekyll` and this `README.md` to the root of your GitHub repository. Upload the extracted files, not the ZIP itself.
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your default branch (usually `main`) and **/(root)**, then save.
6. Open the site URL displayed by GitHub once deployment completes.

You can also open `index.html` directly in a modern browser to preview it. Browser autoplay rules may require clicking a video play control.

## Editing

Search `index.html` for `SECTION 1:` through `SECTION 7:` to find each component in sequence. Keep each component’s matching styles and scripts together. All original images and videos are embedded in the HTML, so there are no local asset folders to upload.
